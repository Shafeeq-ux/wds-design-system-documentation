Section overview

Event sections tell visitors where and when to find Tekion at a show, and what's on. The map shows the venue and booth, and the agenda lists sessions by day.

Recommended placement

On event and conference landing pages, after the event hero.

Audience

Dealers and partners planning their visit to a show.

Goal

Get people to the booth and into sessions, and onto their calendar.

Variants

Use map to show the venue, booth numbers and dates at a glance. Use agenda for the session schedule: day chips switch the day, and each time slot has a location, session title, speakers and an Add to calendar button. Pair them with the Hero event variant.

Content structure and character limits

Limits are calculated from each slot's text style and its maximum width in Figma, so copy fits without breaking the layout. Type your copy into the last column to check it. Limits are proposed until Marketing signs them off.

Map variant. Found in Figma: the vertical padding in the header band (40 and 36px on Desktop, 32 and 24px on Tablet and Mobile) and the 2px gap between the booth and venue lines aren't tokenised, and the map image itself isn't a token.

Variable modes

Like every WDS section, each variant applies the three variable collections: breakpoint for spacing and widths, typography for text sizes, and theme for colours. The same collections and modes carry over to Webflow through the Figma to Webflow plugin. See Figma to Webflow.

Responsive layout behaviour

  • Map: the header band puts the event name, dates and booth in one row on desktop, then stacks them on mobile. The map keeps its width and crops.
  • Agenda: the dates, venue and day chips sit in a column beside the schedule on desktop, and move above it on tablet and mobile. Each time slot stacks its time, location and session on mobile.

Section padding, gaps and widths come from the breakpoint tokens, so the spacing changes automatically at each breakpoint.

Light and dark theme

Both variants are dark in Figma.

Design guidance

Do

  • Show booth numbers and the venue exactly as the organiser publishes them.
  • Use one chip per show day, with the same short date format ("Tue, Feb 17").
  • Give every session an Add to calendar link with the right time zone.

Don't

  • Use the map as the only way to find the booth. Keep the booth number in text.
  • List more than about six sessions per day. Link to a full schedule instead.

Accessibility

  • The venue map needs alt text that gives the booth location in words, for example "Tekion booths 1501 and 1701, Hall A, near the north entrance".
  • Day chips are a single-choice group: use radios or a tablist, with a label such as "Agenda day" (see Chip).
  • Mark each session time up as text, not an image, and use <time datetime>.
  • Each Add to calendar button needs a name that includes the session, such as "Add Extreme Ownership in Dealership Support to calendar".

Marketing handoff checklist

  • Event name, dates, venue and booth numbers checked against the organiser's listing.
  • Venue map exported from Figma with alt text.
  • Agenda: every session has a time, location, title and speakers, with titles within 2 lines.
  • Calendar links tested, with the right time zone.
  • Section and variant chosen from Figma, with its node link.
  • Each variant sets the breakpoint, typography and theme modes.
