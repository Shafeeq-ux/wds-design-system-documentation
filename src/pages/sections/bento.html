Section overview

Bento sections arrange tiles of different sizes in one grid, so one or two ideas can lead while the rest support them. Figma has four bento layouts.

Recommended placement

Mid-page, to summarise a platform or a process.

Audience

Visitors who want the overview at a glance.

Goal

Show several capabilities with a clear hierarchy.

Variants

Bento 5 image has image tiles, bento 5 shows numbered steps, 6 + 1 has six process tiles and a highlight, and 4 + 1 has an intro tile with a CTA beside four features.

Content structure and character limits

Limits are calculated from each slot's text style and its maximum width in Figma, so copy fits without breaking the layout. Type your copy into the last column to check it. Limits are proposed until Marketing signs them off.

Token map

Every layer in this section that uses a Figma variable, taken from the Figma file. Select a layer on the image, or in the list, to see its colour, text, spacing and border variables, their CSS names and values, and the CSS to use. Padding is shaded pink and gaps are striped. Use Issues to find values that aren't tokenised yet.

Five-image variant. Found in Figma: the bento cards' padding (40px on Desktop, 32px on Tablet and Mobile) and 40px gap aren't tokenised, and the card copy mixes a bold lead-in with regular text, so it has no single text style.

Variable modes

Like every WDS section, each variant applies the three variable collections: breakpoint for spacing and widths, typography for text sizes, and theme for colours. The same collections and modes carry over to Webflow through the Figma to Webflow plugin. See Figma to Webflow.

Responsive layout behaviour

  • Tiles keep their grid positions on desktop.
  • On tablet the grid becomes two columns, and on mobile one column, keeping the reading order.
  • Bento tiles use the 24px bento-card radius.

Section padding, gaps and widths come from the breakpoint tokens, so the spacing changes automatically at each breakpoint.

Light and dark theme

The image and numbered bentos are dark; 6 + 1 and 4 + 1 are light.

Design guidance

Do

  • Pick the variant that fits the content, rather than forcing content into a variant.
  • Keep copy within the limits at mobile width, not just desktop.

Don't

  • Use more than 7 tiles.
  • Put a CTA in more than one tile.

Accessibility

  • The visual order of tiles must match the HTML order, so screen readers and keyboards follow the same path.
  • Number steps in text, not only with large decorative numerals.

Marketing handoff checklist

  • Which tile leads.
  • Tile copy within limits.
  • Images cropped for each tile size.
  • Section and variant chosen from Figma, with its node link.
  • Each variant sets the breakpoint, typography and theme modes before it goes through the Figma to Webflow plugin.
  • Copy within every character limit on this page, checked at mobile width.
  • Eyebrow, H2 and description follow the heading rules.
  • Images supplied at 2× with alt text.
  • Reviewed in light and dark if the page supports both.
