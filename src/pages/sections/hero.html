Section overview

The hero is the first section of a page. It states what the page is about in one headline, backs it up with a sentence and leads to one main action. Figma has seven hero variants for different page types.

Recommended placement

First section on every landing and product page, directly under the header. Use only one hero per page.

Audience

Every visitor, most of whom decide in a few seconds whether to keep reading.

Goal

Make the value clear and start the main conversion path (usually a demo request).

Variants

Use default or img 21:9 for product pages, variant 1 when trust is the main concern, content group for inner pages that don't need media, image 1:1 for promotions, and 3-column when the page explains a process.

Content structure and character limits

Limits are calculated from each slot's text style and its maximum width in Figma, so copy fits without breaking the layout. Type your copy into the last column to check it. Limits are proposed until Marketing signs them off.

Variable modes

Like every WDS section, each variant applies the three variable collections: breakpoint for spacing and widths, typography for text sizes, and theme for colours. The same collections and modes carry over to Webflow through the Figma to Webflow plugin. See Figma to Webflow.

Responsive layout behaviour

  • The headline drops from 56px to 40px on tablet and 28px on mobile, using the same style.
  • Stats sit side by side at every size. On mobile their labels move below the number.
  • Media keeps its aspect ratio and fills the container. 21:9 media can be cropped to 16:9 on mobile if the subject would get too small.
  • Two CTAs stack full width on mobile, with the primary first.

Section padding, gaps and widths come from the breakpoint tokens, so the spacing changes automatically at each breakpoint.

Light and dark theme

All hero variants are light in Figma. A dark hero works with the same tokens, but check that media and stat accents still have enough contrast.

Design guidance

Do

  • Pick the variant that fits the content, rather than forcing content into a variant.
  • Keep copy within the limits at mobile width, not just desktop.

Don't

  • Use two primary buttons.
  • Put essential text inside the hero image.
  • Use a carousel as the hero.

Accessibility

  • The hero headline is the page's only h1.
  • The eyebrow is a paragraph, not a heading.
  • Media needs alt text that describes what it shows, or empty alt text if it's decorative.
  • Background video must have a pause control and never autoplay with sound.

Marketing handoff checklist

  • One H1, within 60 characters.
  • Media supplied at 2× for desktop, plus a mobile crop if needed.
  • Stat values checked and sourced.
  • Section and variant chosen from Figma, with its node link.
  • Each variant sets the breakpoint, typography and theme modes before it goes through the Figma to Webflow plugin.
  • Copy within every character limit on this page, checked at mobile width.
  • Eyebrow, H2 and description follow the heading rules.
  • Images supplied at 2× with alt text.
  • Reviewed in light and dark if the page supports both.
