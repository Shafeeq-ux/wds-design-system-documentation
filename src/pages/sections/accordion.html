Section overview

Accordion sections show a list of topics where only one is open at a time, with an image or list that changes with the open row. They let a page cover several roles or steps without getting long.

Recommended placement

Mid-page, for 3 to 6 related topics such as roles, steps or use cases.

Audience

Visitors who want detail on one topic without reading all of them.

Goal

Let people find the topic that applies to them and see it in context.

Variants

Right image and left image pair rows with a visual that changes. The variant opens each role into an icon list.

Content structure and character limits

Limits are calculated from each slot's text style and its maximum width in Figma, so copy fits without breaking the layout. Type your copy into the last column to check it. Limits are proposed until Marketing signs them off.

Responsive layout behaviour

  • On desktop, rows and image sit side by side.
  • On tablet and mobile the image moves inside the open row, directly below its text.

Section padding, gaps and widths come from the breakpoint tokens, so the spacing changes automatically at each breakpoint.

Light and dark theme

Right image is dark in Figma; the other two are light.

Design guidance

Do

  • Pick the variant that fits the content, rather than forcing content into a variant.
  • Keep copy within the limits at mobile width, not just desktop.

Don't

  • Hide essential information, such as pricing, in a closed row.
  • Open several rows at once in the image variants.

Accessibility

  • Each row header is a button with aria-expanded, inside a heading.
  • Keep keyboard focus on the row header when it opens.
  • Content in closed rows must still be reachable by opening the row, not hidden from search engines entirely.

Marketing handoff checklist

  • 3 to 6 rows.
  • One image per row, same aspect ratio.
  • Which row is open by default.
  • Section and variant chosen from Figma, with its node link.
  • Copy within every character limit on this page, checked at mobile width.
  • Eyebrow, H2 and description follow the heading rules.
  • Images supplied at 2× with alt text.
  • Reviewed in light and dark if the page supports both.
