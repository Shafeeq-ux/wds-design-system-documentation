Overview

WDS ships as three files: the tokens, the component and section styles, and a small script for interactive behaviour. There's no framework and no build step required to use them.

FileWhat it isSize
css/tokens.cssEvery design token as a CSS custom property, plus the 27 text style classes59 KB, 7 KB gzipped
css/wds.cssLayout, components and sections33 KB, 6 KB gzipped
js/wds.jsPrimary button hover and disclosure menusUnder 2 KB

Setup

1. Add the files

<link rel="stylesheet" href="/css/tokens.css">
<link rel="stylesheet" href="/css/wds.css">
<script src="/js/wds.js" defer></script>

2. Load the font

Self-host the Tekion Sans variable WOFF2 files (see Type in use) and declare them under the family name the tokens use:

@font-face {
  font-family: "Tekion Sans";
  src: url("/fonts/TekionSans-VF.woff2") format("woff2-variations");
  font-weight: 200 900;
  font-stretch: 75% 125%;
  font-display: swap;
}

Without the font, text falls back to Inter and then the system font.

3. Start a page

<!doctype html>
<html lang="en-US">
<head>…</head>
<body class="wds">
  <a class="skip-link" href="#main">Skip to content</a>
  <header class="wds-header" data-theme="dark">…</header>
  <main id="main">
    <section class="wds-hero">…</section>
  </main>
  <footer class="wds-footer" data-theme="dark">…</footer>
</body>
</html>

The .wds class sets the font, text colour and page background. Copy each component's markup from its page, under Developer implementation.

Known limitations

  • Accordion, Carousel, Tabbed, Pop-up and the header menus have no final interaction design yet. See their pages for status.
  • Section CSS covers the sections with live examples. The others are documented from Figma and need building.
  • The Tekion Sans font files aren't distributed through this public site.
