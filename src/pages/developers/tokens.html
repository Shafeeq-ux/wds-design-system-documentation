Overview

All 581 Figma variables are exported to JSON and compiled to CSS custom properties on every build. Use the CSS in the browser, and the JSON to feed other tools (a CMS theme, email templates, a native app).

Setup

Naming

CSS names follow the Figma path. A leading category (background, components, gradient, spacing, core) is dropped, and so is a segment the next one repeats.

Figma variableCSS custom property
background/bg-page--wds-bg-page
text/text-primary--wds-text-primary
color/gray/gray-800--wds-color-gray-800
core/size-16--wds-size-16
spacing/padding/p-24--wds-padding-p-24
border/border-radius/button--wds-border-radius-button
components/input/input-border--wds-input-border
spacing/width/container-max-width--wds-width-container-max-width
headline-1/font-size--wds-headline-1-font-size
Text style Headline/headline-1Class .wds-headline-1

The build fails if two Figma variables would produce the same CSS name.

Which layer to use

  • Component tokens (--wds-btn-*, --wds-input-*) inside components.
  • Semantic tokens (--wds-bg-*, --wds-text-*, --wds-border-*) everywhere else.
  • Primitives (--wds-color-*, --wds-size-*) only when you're defining a new semantic token.

Code examples

.promo-card {
  padding: var(--wds-width-3-col-card-top-bottom-padding) var(--wds-width-3-col-card-right-left-padding);
  border: var(--wds-border-width-bw-1) solid var(--wds-border-subtle);
  border-radius: var(--wds-border-radius-bento-card);
  background: var(--wds-bg-elevated);
  color: var(--wds-text-primary);
}
.promo-card h3 { /* or add class="wds-headline-4" */
  font-size: var(--wds-headline-4-font-size);
  line-height: var(--wds-headline-4-line-height);
}

Updating tokens

  1. Change the variable in the WDS 3.0 Figma file.
  2. Run scripts/figma-export.js in the file for each changed collection and paste the result into tokens/wds-tokens.json.
  3. Run npm run build, then review the diff in css/tokens.css and the contrast results on the Colour page.

Known limitations

  • Theme tokens are emitted as resolved values per theme, not as var() references to primitives. The alias is kept as a comment.
  • Four input and checkbox backgrounds are an alias with 15% opacity in Figma. They're exported as 8-digit hex.
