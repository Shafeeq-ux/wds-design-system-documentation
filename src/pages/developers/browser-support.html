Overview

WDS supports the last two major versions of evergreen browsers. Check tekion.com analytics before launch to confirm this covers your visitors. It lets the system use modern CSS without workarounds.

BrowserSupported
Chrome, EdgeLast 2 versions
Safari (macOS and iOS)16.4 and later
FirefoxLast 2 versions (121 and later)
Samsung InternetLast 2 versions
Internet ExplorerNot supported

Setup

The CSS features WDS depends on, and what happens without them:

FeatureUsed forWithout it
Custom propertiesEvery tokenRequired
:where()Zero-specificity box sizingElements fall back to content-box sizing
:has()Input error and disabled surfaces, checkbox labelsUse the is-error and is-disabled classes instead
backdrop-filterPrimary button hover blur, docs top barNo blur; the button still works
CSS masksCheckbox tick, FAQ plus/minusIcons don't show (Safari 15.4+ supports them)
mix-blend-mode: plus-lighterPrimary button pointer glowGlow is a plain overlay
font-stretch with a variable fontHeadline and body widthsText renders at 100% width
<details>, <dialog>FAQ, pop-upsRequired

Code examples

If you need to support an older browser, add the state classes yourself, which the CSS already accepts:

<div class="wds-input is-error">…</div>

Known limitations

  • The primary button's hover blur is noticeably smoother in Chromium browsers than in Safari.
  • Firefox only supports font-stretch fully with variable fonts that declare a width axis, which Tekion Sans VF does.
