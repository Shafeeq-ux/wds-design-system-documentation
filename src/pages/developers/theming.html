Overview

The theme collection in Figma has a light and a dark mode, and tokens.css turns them into three layers of CSS. Components only ever use theme tokens, so switching the theme switches every component.

/* 1. Light by default */
:root, [data-theme="light"] { --wds-bg-page: #ffffff; … }

/* 2. Dark when forced */
[data-theme="dark"] { --wds-bg-page: #0a0c10; … }

/* 3. Dark when the OS asks for it, unless light is forced */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --wds-bg-page: #0a0c10; … }
}

Setup

GoalDo this
Follow the visitor's OS settingNothing. It's the default.
Always light<html data-theme="light">
Always dark<html data-theme="dark">
One dark section on a light page<section data-theme="dark">. Tokens re-resolve inside it.
One light card in a dark section<div data-theme="light">

The scope also sets color-scheme, so native scrollbars and form controls match. Give the scoped element a background (var(--wds-bg-page)); the attribute only changes the tokens.

Code examples

Fixed themes from Figma

  • Header and footer are always dark: <header class="wds-header" data-theme="dark">.
  • Image banner card is always light: <div class="wds-promo__card" data-theme="light">.
  • Sections have a default theme in Figma, listed on each section page. Set it with data-theme on the section.

A theme switch

const root = document.documentElement;
function setTheme(choice) {            // 'light' | 'dark' | 'system'
  if (choice === 'system') root.removeAttribute('data-theme');
  else root.setAttribute('data-theme', choice);
  try { localStorage.setItem('theme', choice); } catch {}
}

Known limitations

  • Gradients redeclare under every [data-theme] so nested scopes pick up their own stops. Other composite values may need the same treatment.
  • The image banner gradient and the primary button image aren't tokenised, so they don't change with the theme.
  • Images and illustrations don't switch automatically. Use <picture> with media="(prefers-color-scheme: dark)" where a dark version exists.
