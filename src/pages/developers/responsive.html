Overview

The typography and breakpoint collections in Figma each have desktop, tablet and mobile modes. tokens.css sets desktop values on :root and overrides them in two media queries, so components never need their own breakpoints for size and spacing.

In Figma and Webflow the same switch happens through variable modes: each section variant sets breakpoint and typography to desktop, tablet or mobile. See Figma to Webflow.

:root { --wds-headline-1-font-size: 56px; --wds-width-container-max-width: 1420px; … }
@media (max-width: 1279px) { :root { --wds-headline-1-font-size: 40px; --wds-width-container-max-width: 640px; … } }
@media (max-width: 767px)  { :root { --wds-headline-1-font-size: 28px; --wds-width-container-max-width: 342px; … } }

Use the same two values when a layout itself needs to change (for example columns becoming rows). CSS custom properties can't be used inside media queries, so the numbers are written out in wds.css. The breakpoints are also in wds-css-variables.json.

Code examples

/* Size and spacing: just use tokens, they switch on their own */
.my-section {
  padding: var(--wds-padding-section-top-padding-default) var(--wds-padding-section-right-left-padding-default);
}

/* Layout changes: use the WDS breakpoints */
.my-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: var(--wds-gap-g-24); }
@media (max-width: 1279px) { .my-grid { grid-template-columns: 1fr 1fr; } }
@media (max-width: 767px)  { .my-grid { grid-template-columns: 1fr; } }

Testing

  • Use the viewport switch on any live preview in these docs. It renders the example at 1440, 768 and 390px, so real media queries fire.
  • Check the in-between widths too: 1024px (tablet tokens on a laptop) and 320px (smallest phones).
  • Check at 200% zoom, which triggers the tablet or mobile layout on most laptops.

Known limitations

  • Between 768 and 1279px the content stays at the 640px tablet container. Wide tablets and small laptops show generous side space. Design should confirm whether a wider in-between container is wanted.
  • The CSS switch points are a development choice. Figma only defines the three frame widths.
