Overview

Breadcrumbs show where a page sits in the site and link back up the hierarchy. Figma has three components: Breadcrumb Item (one link), Breadcrumb Separator (a 16px chevron) and Breadcrumbs, the trail built from them in six layouts.

LayoutUse for
2 to 5 levelsEvery level from the homepage to the current page
CollapsedMore than five levels: the first item and the last two stay, and "…" opens the rest
CompactMobile: only a back link to the parent page

Variants and states

The Hover, Pressed and Focus items are forced, so you can compare them side by side. Select "…" in the Collapsed trail to show the hidden levels.

  • Default, Hover and Pressed are links. They darken and underline on hover and press.
  • Current is the last item, the page you're on. It's muted, has no hover or underline, and isn't a link.
  • Focus shows the keyboard ring on links. Current never takes focus.
  • Separators are decorative and never interactive.

Design guidance

Do

  • Use breadcrumbs when the site has three or more levels.
  • Start with the homepage and end with the current page.
  • Use the page's real title for each level, shortened if needed.

Don't

  • Use breadcrumbs on flat sites or in single-step flows.
  • Make the current page a link.
  • Use breadcrumbs instead of the main navigation.

Responsive behaviour

  • At 767px and below the trail switches to Compact automatically: only a back link to the parent shows. Add .wds-breadcrumbs--compact to force it at any width.
  • On wider screens a long trail wraps rather than overflowing. Above five levels, use Collapsed instead.

Light and dark theme

  • Links are gray-800 in light mode and white in dark mode. Current is gray-500 in light mode and gray-400 in dark mode.
  • The separator uses icon-tertiary in both themes.

Microcopy and limits

  • Use each page's title, in the same case as the page: "About us", "Our Leadership".
  • Keep each level to about 30 characters (proposed). Shorten long page titles rather than letting the trail wrap.

Developer implementation

<nav class="wds-breadcrumbs" aria-label="Breadcrumb">
  <ol>
    <li><a href="/">Homepage</a></li>
    <li><a href="/about-us">About us</a></li>
    <li><span aria-current="page">Our Leadership</span></li>
  </ol>
</nav>

<!-- Collapsed: hide the middle levels behind a button (js/wds.js reveals them) -->
<li><button class="wds-breadcrumbs__more" type="button" aria-label="Show 2 more levels">…</button></li>
<li hidden><a href="/about-us">About us</a></li>
<li hidden><a href="/company">Company</a></li>

Separators are drawn by CSS between list items, so they're never read out or focused. Load js/wds.js for the Collapsed "…" button.

Tokens

Accessibility

  • Landmark: wrap the trail in <nav aria-label="Breadcrumb"> with an ordered list (WCAG 1.3.1).
  • Current page: mark the last item with aria-current="page" and don't make it a link (WCAG 4.1.2).
  • Separators: decorative, drawn by CSS, so screen readers skip them.
  • Collapsed: the "…" button needs an accessible name, such as "Show 2 more levels", and moves focus to the first revealed link.
  • Target size: links are 16px high, with an invisible hit area of at least 24px (WCAG 2.5.8).

Acceptance checklist

  • The trail is a nav with an ordered list, starting at the homepage.
  • The last item is the current page, not a link, with aria-current="page".
  • Hover and Pressed underline; Focus shows the ring.
  • Trails over five levels use Collapsed.
  • Mobile shows the Compact back link.
