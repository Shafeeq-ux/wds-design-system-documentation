Tekion Website Design System

One system for every Tekion web page

WDS 3.0 is the shared set of foundations, components and section layouts that Design, Development and Marketing use to build tekion.com. Each page explains what to use, how it adapts from desktop to mobile, how it looks in light and dark, and how much copy each slot can hold.

Every page adapts and themes

Each component and section has a live preview. Switch the viewport to see the tablet and mobile layout, and switch the theme to check light and dark. The theme buttons in the top bar change the whole site.

Who owns what

Design

Owns the system and keeps it true to Figma.

  • Foundations, visual rules and interaction principles
  • Approved patterns and component anatomy
  • Figma references, states and accessibility expectations

Development

Builds from the component pages and keeps technical detail current.

  • Responsive views and light and dark theme handling
  • Asset links, code references and known limitations
  • Accessibility implementation notes

Marketing

Composes pages and writes to the content limits.

  • Section layouts and page composition
  • Content writing, campaign messaging and character limits
  • Approved examples, CTA guidance and asset usage notes
