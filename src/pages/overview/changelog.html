3.0.1 · 17 October 2026

  • Token map (pilot) on Hero, Card grid and Button: the Figma render with every layer's colour, type, spacing and border variables, their CSS names and values per breakpoint and theme, padding and gap overlays, CSS for each layer, and untokenised values flagged as issues.
  • Figma to Webflow: a new page explaining how designs are converted into Webflow with the Figma to Webflow plugin, and the three variable collections (breakpoint, typography, theme) every section applies.
  • Variable modes section added to every section page, with a Figma audit of all 174 section, header and banner variants.

Open issues found

  • Hero default: the gap between each stat value and its label is a hardcoded 8px.
  • Card grid 4-column: the gaps inside cards (64, 37 and 80px) aren't tokenised, and the card copy has no single text style.
  • Button: the tertiary icon circle has a hardcoded 6px padding.
  • Accordion left-image: Desktop and Tablet variants don't set breakpoint or typography modes.
  • Legal implementation terms: the Tablet variant uses the desktop typography mode.
  • Legal disclaimer: the Desktop variant sets no modes.

3.0.0 · 17 October 2026

First release of the WDS 3.0 documentation site.

Documentation

  • Overview, Developer resources and Page templates: purpose, accessibility standard, contribution, governance and versioning; getting started, tokens, theming, responsive and browser support; four page templates.
  • Content guidelines: voice and tone, headings, CTA labels, character limits with a calculator, alt text, accessibility copy, localisation, and SEO and metadata.
  • Section layouts: 16 sections, 55 variants rendered from Figma, character limits for 90 content slots, and live examples for Hero, Card grid, Feature, Stats, FAQ and Footer.
  • Components: Button, Input, Checkbox, Radio button (proposed), Header and Banner, with live examples.
  • Foundations: colour with contrast checks, typography, type in use, spacing, grid and breakpoints, borders and radii, gradients, elevation, motion, logos and icons.
  • Site: tokens generated from Figma, light/dark/system theme, viewport previews, search, and a link checker.

Open issues found during documentation

  • Primary button colour tokens don't match the image fill the component uses, and are white on white in dark mode.
  • Input radius token (9999) doesn't match the 8px components.
  • Input and checkbox borders, teal text and light-mode error text are below WCAG contrast minimums.
  • No Radio button component, focus states, elevation or motion tokens in Figma.
  • Header menus and the mobile menu panel aren't designed.
  • CTA wording and heading case are inconsistent in a few places.
