Purpose

WDS 3.0 is the design system for Tekion's marketing website. It gives Design, Development and Marketing one shared source for how pages look, behave and read, so new pages are faster to make and consistent with the rest of the site.

Scope

In scopeOut of scope
tekion.com marketing pages, campaign and event pages, landing pages and legal pagesThe Tekion product UI (ARC, T1 and partner apps), which has its own design system
Foundations: colour, type, spacing, grid, icons, logosPrint, presentations and email templates. The Type in use page covers fonts for those.
Web components and 16 section layoutsCMS configuration and page-builder setup
Content guidelines and character limitsBrand strategy and messaging frameworks

Principles

One source of truth

Figma variables generate the CSS. If it isn't in Figma, it isn't in the system yet.

Responsive by default

Every token, component and section has a desktop, tablet and mobile value.

Accessible for everyone

WCAG 2.2 AA is the minimum, checked in both themes.

Content fits by design

Every text slot has a character limit, so copy and layout are planned together.

How to use it

  • Designers: start in the WDS 3.0 Figma file, use its components and variables, and check the matching page here for guidance and open issues.
  • Developers: start with Getting started, and use each component page's Developer implementation section.
  • Marketers: pick a section from Section layouts, write to its character limits, and work through its handoff checklist.
