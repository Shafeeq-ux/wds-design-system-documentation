Review rules

Governance note. Update the relevant page before releasing any WDS 3.0 change broadly. Cross-functional review is required when a change affects visual design, behaviour, accessibility or content limits.

ChangeReviewers
Typo or wording fix in the docsPage owner
New example or clarificationPage owner
Token value changeDesign + Development
New or changed component or sectionDesign + Development + Marketing
Accessibility-affecting changeDesign + Development, with an accessibility check
Character limit changeMarketing + Design

Versioning

WDS uses semantic versioning: major.minor.patch. The current version is 3.0.0.

BumpWhenExample
Major (4.0.0)Breaking: renamed or removed tokens, classes or sectionsRenaming --wds-bg-page
Minor (3.1.0)New components, sections, variants or tokensAdding the Radio button component
Patch (3.0.1)Fixes that don't change the APIFixing a token's dark value

Every release gets a Changelog entry. Breaking changes are announced to all three teams before release.
