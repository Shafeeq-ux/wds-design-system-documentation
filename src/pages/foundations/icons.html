Overview

WDS has two kinds of icon:

  • Utility icons (16px, single colour): arrows, close, menu, check and media controls inside components.
  • Feature icons (48px, two-tone): illustrate a benefit or step in feature, card and process sections. There are 65, 38 of them documented with search keywords.

Utility icons

Each icon uses currentColor, so it takes the colour of the text around it. Download any icon as an SVG file, or copy its SVG code to paste inline.

Sizes and colour

SizeUse
16pxDefault. Inside buttons, inputs, accordions and links.
20pxHeader and banner controls.
24pxVideo player controls and standalone icon buttons.

Colour icons with icon tokens: icon-primary by default, icon-secondary for supporting icons, icon-disabled for disabled controls, and the status icon tokens for feedback. See Colour › Icons.

Feature icons

Feature icons come in light and dark versions in Figma. The light versions are below: download any icon as an SVG file, or copy its SVG code. Use the dark version from Figma in dark sections.

Accessibility

  • Icons next to a text label are decorative: add aria-hidden="true" to the SVG.
  • Icon-only buttons need an accessible name, such as aria-label="Close".
  • An icon that carries meaning on its own needs 3:1 contrast against its background (WCAG 1.4.11).
  • Keep the hit area at least 24 × 24px even when the icon is 16px (WCAG 2.5.8).

Implementation

<button class="wds-btn wds-btn--secondary">
  Learn more
  <svg aria-hidden="true" width="16" height="16">…</svg>
</button>

Inline the SVG, or use it as a CSS mask, so currentColor works. An <img> tag can't inherit colour.
