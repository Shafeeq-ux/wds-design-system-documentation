Overview

WDS has 13 gradients. Each one is a Figma paint style (the shape and stop positions) whose colours come from theme variables, so a gradient can change colour between light and dark.

  • Background gradients (gradient-bg-*): soft, light washes behind heroes and feature sections.
  • Accent gradients: saturated blends for campaign moments and product highlights. Most fade to near-black in light mode and to white in dark mode.

Work in progress. The Gradients page in Figma is still in progress. Usage rules below are proposed.

All gradients

Each gradient is shown in light and dark. Select a name to copy its CSS variable.

Usage guidance

Do

  • Use background gradients behind one hero or feature section per page.
  • Put text on the lightest part of the gradient, and check its contrast at that point.
  • Use the CSS variable so the gradient follows the theme.

Don't

  • Put body copy over the saturated middle of an accent gradient.
  • Stack two gradient sections next to each other.
  • Recreate a gradient by hand with different stops.

Light and dark theme

In dark mode the beach gradient becomes plain white, and the accent gradients swap their dark end for white. Check any gradient-backed section in both themes before launch. A dark-mode gradient may need text-primary instead of text-on-dark.

Developer notes

.hero { background: var(--wds-gradient-bg-ocean); }

Linear gradient angles are converted from the Figma paint styles. Figma radial gradients can be rotated ellipses, which CSS can't draw, so the radial centres are exact but their shapes are approximate. Compare against Figma when a radial gradient is a key visual.
