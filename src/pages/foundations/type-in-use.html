Overview

Tekion uses one family, Tekion Sans, for everything people read: web pages, product UI, presentations and documents. A monospace stack is used only for code and anything that needs fixed-width characters.

Two family names

Tekion Sans ships in two forms with different family names, so both can be installed on one machine without clashing:

  • Tekion Sans: static files in fixed weights. This is what most people install, and the only version that works in PowerPoint and Word.
  • Tekion Sans VF: the variable font, with a continuous weight axis (200–900) and width axis (75–125). Marketing designers use it for brand, campaign and print work.

Duplicate font installs are invisible in font menus and take days to diagnose. Keeping the names different prevents that.

The marketing site uses the variable font because WDS text styles depend on the width axis: headlines at 110%, statistics at 125% and body at 105%. The product UI uses only fixed weights and no width variation, so the static files are 2.5 times lighter there.

In CSS, the width tokens map to font-stretch, for example font-stretch: var(--wds-headline-1-font-stretch). Static fonts ignore it, which is why the static family can't reproduce WDS headlines exactly.

Rules for presentations

Do

  • Use the static Tekion Sans in PowerPoint and Word.
  • Export a PDF to share a deck outside Tekion.
  • Build condensed type in Figma, where the width axis is real.

Don't

  • Use Tekion Sans VF in decks. Recipients won't have it and it substitutes silently.
  • Fake condensed type with character scaling. It squeezes the strokes and breaks the letterforms.

What developers must know

Send box-drawing characters to the monospace stack

Tekion Sans has no box-drawing or block glyphs. Any run that contains characters like ├── └── █ ░ ▁▇ (file trees, ASCII tables, progress bars, sparklines) must use --font-mono, not just fenced code blocks. Otherwise the browser falls back to another font halfway through a line and the alignment collapses.

Keep monospace line height at 1.31 or below

Box-drawing verticals are 1.31em tall. Any looser and the vertical lines in a file tree break into dashes.

Monospace is never downloaded

Code renders in the visitor's own system font (SF Mono, Consolas and so on) through --font-mono. That costs nothing to load and covers box-drawing on every platform. Geist Mono exists only on designers' machines so mockups look right. It's never shipped.

Character support

  • No emoji and no keyboard symbols such as ⌘ ⌥ ⇧ ⏎. Figma substitutes them silently, so expect a different font when you type them.
  • Greek is limited to µ and π.
  • Numbers are proportional by default, which is right for prose. Turn on tabular figures for tables, metrics and identifiers. Tabular figures also give you a slashed zero, which matters for VINs and repair-order numbers.
