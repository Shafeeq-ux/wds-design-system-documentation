Overview

WDS uses one typeface, Tekion Sans, for every heading, paragraph, label and button. The system has 27 text styles in four families: headlines, statistics, body and labels. Each style has its own values for desktop, tablet and mobile, so a heading shrinks at the right breakpoint without anyone choosing a new style.

About the samples on this site. Tekion Sans is a licensed font and isn't served by this public site. If you have it installed, the samples use it. Otherwise they fall back to Inter, which is close in proportion but narrower.

Type scale

Sizes are font size / line height in pixels. Select a class name to copy it. The samples use live tokens, so they render at your current breakpoint: resize the window to watch them change.

Headlines

Headlines are SemiBold (600) at 110% width. The -reg versions of headline 2, 3 and 4 are Regular (400). Use them for a quieter heading, or for a second line beneath a SemiBold one.

StyleHTML elementUse for
.wds-headline-1h1The page title in a hero. Once per page.
.wds-headline-2h2Section titles.
.wds-headline-3h2 or h3Sub-section titles and large feature titles.
.wds-headline-4h3Card titles in 2- and 3-column grids, tab titles.
.wds-headline-5h3 or h4Card titles in 4-column grids, accordion rows.
.wds-headline-6h4Small card titles, FAQ questions, footer column headings.

A style is a visual size, not a heading level. Pick the HTML level from the page outline (one h1, no skipped levels) and the style from the layout.

Statistics

.wds-statistics (Figma: Headline/statistics) is Light (300) at 125% width, made for large numbers in the Stats section. Turn on tabular figures (font-variant-numeric: tabular-nums) when numbers sit in a row, so they line up.

Body

Body styles run from 20px (body 1) to 12px (body 5), each in Regular, Medium and SemiBold (named -bold). Body width is 105%.

StyleUse for
.wds-body-1-*Hero sub-copy and lead paragraphs.
.wds-body-2-*Section descriptions and feature copy.
.wds-body-3-*Default paragraph text, card body, form fields.
.wds-body-4-*Captions, helper text, footer links, banner messages.
.wds-body-5-*Legal small print and metadata. Never for anything people must read to complete a task.

Labels

  • .wds-button: 14px Medium. Every button label.
  • .wds-overline: 12px SemiBold, uppercase, 1.2px letter spacing. The eyebrow above a section title. Keep it to a few words.

Responsive behaviour

The typography collection in Figma has three modes. The CSS switches values at the same breakpoints as the layout grid:

ModeViewportHeadline 1Headline 2Body 1
Desktop1280px and up56 / 6440 / 4820 / 28
Tablet768–1279px40 / 4432 / 4020 / 28
Mobile767px and below28 / 3228 / 3618 / 26

Negative letter spacing on large headlines (−1px for headline 1 on desktop) relaxes to 0 on mobile, where tight tracking hurts legibility at small sizes.

The mobile and tablet values come from Figma, but the exact switch points (767px and 1279px) are a development choice. Figma frames are drawn at 390, 768 and 1920px.

Light and dark theme

Text styles carry no colour. Pair them with a text token: text-primary for headings and body, text-secondary for supporting copy, and text-tertiary for captions. These are checked for contrast in both themes on the Colour page. Light (300) weights look thinner on dark backgrounds, so keep Statistics at 32px or larger in dark mode.

Accessibility

  • Set sizes in the CSS with the tokens, and don't stop text from resizing. Pages must work at 200% zoom (WCAG 1.4.4) and with text spacing overridden (WCAG 1.4.12).
  • Keep paragraphs to about 60–80 characters per line. The p-width-centre token (720px) does this for body 1 and body 2.
  • Don't use uppercase for anything longer than an overline. It's harder to read and screen readers may spell it out.
  • Don't fake bold, italic or condensed. Use the real weights and the width axis.
