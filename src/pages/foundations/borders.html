Overview

Border widths and corner radii follow the same pattern as spacing: a primitive scale, plus component tokens that alias it. WDS is a soft, rounded system. Buttons and single-line inputs are full pills, and cards use large radii.

Border radius

ElementTokenValue
Buttons--wds-border-radius-buttonFull
Single-line inputs--wds-border-radius-inputFull
Text areas--wds-border-radius-textarea16px
Bento cards--wds-border-radius-bento-card24px
Checkboxes--wds-border-radius-checkbox0 (square)

Border width

Inputs use a 1px border that thickens to 2px on focus (border-width-input-focus). Swapping widths can shift the layout by 1px, so draw the extra pixel with an inset box-shadow or reserve it with padding.

Border colour

Border colours are theme tokens: border-subtle, border-default, border-strong, border-focus, border-disabled, border-error and border-success. See Colour › Borders.

Accessibility

  • A border that's the only way to see a control, like an input outline, needs 3:1 contrast against its background (WCAG 1.4.11). border-default doesn't meet this today. See Known issues.
  • Focus rings use border-focus at 2px with a 2–3px offset, so they stay visible on any surface.
