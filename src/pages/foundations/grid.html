Overview

WDS pages are designed at three widths. The breakpoint collection in Figma holds every value that changes between them: containers, text widths, card widths and section spacing. In CSS each token has one name, and its value switches automatically at the breakpoint.

Work in progress. The Responsive and Grids pages in Figma are still being drawn. The values below come from the variables, which are complete. A formal column grid hasn't been defined yet.

Containers

Use container-max-width for most sections. Offset containers narrow the content for editorial sections, forms and centred CTAs.

The device-width token records the Figma frame width (1920, 768, 390). It's for design reference, not layout.

Text widths

Headings and paragraphs have their own maximum widths so lines don't run too long on wide screens. On mobile they all match the 342px container.

Card columns

Card grids come in 1 to 5 columns. Each column count has a minimum and maximum card width plus its own inner padding, all of which change by breakpoint. On mobile, every grid becomes a single 342px column except the 5-column grid. Its 156px minimum lets two cards sit side by side, which the live example uses.

The space between cards isn't tokenised yet. The live example uses 24px (g-24) until Design confirms the value.

Section spacing

Every section has top, bottom and side padding. Default suits most sections. 2x is for heroes and sections that need extra separation. None lets two sections with the same background run together.
