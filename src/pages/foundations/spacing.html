Overview

WDS spacing is built on a 4px scale. The core/size primitives (0–200, plus 9999 for pill shapes) feed two sets of tokens: padding (p-*) for space inside a container, and gap (g-*) for space between items. Both use the same values, so pick by intent, not by number.

Section-level spacing that changes at each breakpoint, such as section padding and the gap between a title and its description, lives on the Grid & breakpoints page.

Usage guidance

Do

  • Use a token for every margin, padding and gap.
  • Use bigger steps between groups than within them, so related items read as one unit.
  • Use the responsive section tokens for space between sections.

Don't

  • Use values that aren't on the scale, such as 10px or 18px.
  • Use a fixed desktop value for section padding. It won't shrink on mobile.
