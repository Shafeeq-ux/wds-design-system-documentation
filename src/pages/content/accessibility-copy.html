Pattern purpose

Some copy is mostly heard rather than seen: link text read out of context, button names, form labels, error messages and hidden text for screen readers. This page covers how to write it so the site works for everyone.

Voice and tone

The same voice as visible copy, only more literal. Hidden text should describe, not market.

Writing rules

Links and buttons

  • Make each link make sense on its own. Screen reader users often list all links on a page (WCAG 2.4.4).
  • When the visible label repeats ("Read More"), add hidden context with .visually-hidden.
  • Name icon-only buttons by their action: "Play video", "Close", "Next slide". Not "Button" or "Icon".
  • Say when a link opens a new tab: "(opens in a new tab)", in visually hidden text.

Forms

  • Every field has a visible label. Placeholders are examples, not labels.
  • Error messages say what's wrong and how to fix it: "Enter a 10-digit phone number", not "Invalid".
  • Say which fields are required before people start ("All fields are required" or mark the optional ones).
  • After submitting, confirm what happened and what comes next.

Landmarks and page structure

  • Give each nav a distinct name: "Main", "Footer", "Breadcrumb".
  • The skip link reads "Skip to content".
  • The page <title> is unique and starts with the page's own name.

Plain language

  • Spell out abbreviations on first use: "dealer management system (DMS)".
  • Write numbers as numerals, and spell out symbols screen readers misread where it matters: "per repair order" rather than "/RO" in hidden text.
  • Avoid directions that depend on sight: "the button on the right" or "the green link".

Approved examples

Approved

  • <a>Read More<span class="visually-hidden"> about Salesperson AI</span></a>
  • aria-label="Open menu" / "Close menu"
  • "Select a role"

Not approved

  • "Click here"
  • aria-label="hamburger icon"
  • "Error: field invalid"

Accessibility and localisation notes

  • Hidden text is translated too. Keep it in the CMS, not hard-coded in templates.
  • If an aria-label replaces visible text, it must contain that visible text (WCAG 2.5.3).
  • Set lang on the page, and on any phrase in another language (WCAG 3.1.1, 3.1.2).
