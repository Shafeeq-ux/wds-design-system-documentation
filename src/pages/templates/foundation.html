How to use this template

  1. Add the page to src/nav.json under foundation, with its title, description, owner and Figma node.
  2. Create src/pages/foundations/your-page.html and paste the HTML below.
  3. Fill in every section. Remove a section only if it truly doesn't apply, and say why.
  4. Leave the status as Proposed until the page has been reviewed (see Governance).
  5. Run npm run check to build and check links.

Use this template to document a new foundation such as elevation or motion.

Template outline

  1. Overview: What this foundation is, and the layers it has (primitive, semantic, component).
  2. Tokens: Generated tables, for example <!--wds:theme background/--> or <!--wds:scale spacing/gap/g--->.
  3. Usage guidance: Do and don't, with examples.
  4. Responsive behaviour: How values change at tablet and mobile, or "Doesn't change".
  5. Light and dark theme: Differences between themes.
  6. Accessibility: Contrast, motion or sizing rules, with WCAG references.
  7. Figma references: Links to the Figma page and variables.
