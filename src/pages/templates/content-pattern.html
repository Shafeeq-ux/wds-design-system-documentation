How to use this template

  1. Add the page to src/nav.json under Content guidelines, with its title, description, owner and Figma node.
  2. Create src/pages/content/your-page.html and paste the HTML below.
  3. Fill in every section. Remove a section only if it truly doesn't apply, and say why.
  4. Leave the status as Proposed until the page has been reviewed (see Governance).
  5. Run npm run check to build and check links.

Use this template to document a new content guideline.

Template outline

  1. Pattern purpose: What this copy does and where it appears.
  2. Voice and tone: How the voice applies here.
  3. Writing rules: Specific, testable rules.
  4. Character or word limits: A table of limits, or a link to Character limits.
  5. Approved examples: Approved and not approved, side by side.
  6. Accessibility and localisation notes: Screen reader, translation and expansion notes.
