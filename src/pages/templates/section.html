How to use this template

  1. Add the page to src/nav.json under section, with its title, description, owner and Figma node.
  2. Create src/pages/sections/your-page.html and paste the HTML below.
  3. Fill in every section. Remove a section only if it truly doesn't apply, and say why.
  4. Leave the status as Proposed until the page has been reviewed (see Governance).
  5. Run npm run check to build and check links.

Use this template to document a new section layout.

Template outline

  1. Section overview: What it is for, plus a meta grid of placement, audience and goal.
  2. Variants: Add the section to src/data/sections.json, then use <!--wds:section-sets KEY--> for the Figma renders.
  3. Content structure and character limits: <!--wds:section-limits KEY--> builds the table from the slots in sections.json.
  4. Responsive layout behaviour: Desktop, tablet and mobile layout.
  5. Light and dark theme: The Figma default theme, and whether it works in the other.
  6. Design guidance: Do and don't.
  7. Accessibility: Landmarks, headings, keyboard and media rules.
  8. Marketing handoff checklist: Everything Marketing must supply.
