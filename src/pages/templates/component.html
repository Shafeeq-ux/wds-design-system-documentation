How to use this template

  1. Add the page to src/nav.json under component, with its title, description, owner and Figma node.
  2. Create src/pages/components/your-page.html and paste the HTML below.
  3. Fill in every section. Remove a section only if it truly doesn't apply, and say why.
  4. Leave the status as Proposed until the page has been reviewed (see Governance).
  5. Run npm run check to build and check links.

Use this template to document a new component.

Template outline

  1. Overview: What it is, when to use it, and a table of its types.
  2. Variants and states: A live preview: <div class="doc-preview" data-src="/examples/NAME.html" data-title="NAME"></div>
  3. Anatomy: A table of parts with sizes, spacing and tokens.
  4. Design guidance: Do and don't.
  5. Responsive behaviour: What changes at tablet and mobile.
  6. Light and dark theme: How it looks in each theme, and any fixed theme.
  7. Microcopy and limits: A character-limit table for every text slot.
  8. Developer implementation: HTML, classes mapped to Figma variants, timing, and tokens: <!--wds:theme components/NAME/-->.
  9. Accessibility: Semantics, keyboard, focus, target size, contrast, with WCAG references.
  10. Figma, asset and code references: Figma node links, downloads, CSS and JS file sections.
  11. Acceptance checklist: What must be true before it ships.
